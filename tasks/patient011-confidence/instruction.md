Read this adult transthoracic echocardiogram and fill out the findings form (findings_form.csv) - each column is one question about the study. Exam_DICOM/ contains the study exported from the scanner. In Exam_VendorNeutral/ you’ll find stills annotated with measurements that the sonographer retook so they’re not in the measurement data in clinical_context.docx but are relevant to the study. There’s also a manifest in Exam_Data that shows which DICOMs the annotated images correspond to. Saved values are sometimes off so make sure you check the measurement values against the images before you rely on it. 

In the form, for columns marked select_all_that_apply, list every option that applies, separated by |. findings_form_options.json contains the multiple choice answers options when the question applies. Questions with answer_only_if apply only when that condition is met by your own earlier answers (for example, a mass's details only if you said a mass needs to be in the report). Otherwise leave the cell empty. This draft will go to the cardiologist for review before it gets sent off, so items that shouldn't be included in the report due to a lack of evidence, just give your best guess and use the corresponding confidence column.
