# tte-echo-bench/patient007-summary

The agent writes the summary (headline + impression) of the patient007 TTE report from completed
structured findings.

| Path | What it is | Who sees it |
| - | - | - |
| `environment/findings/` | The patient007 report templates filled with expert alex.ryzhikov's answers (Tally submission `LDL75ZJ`, `expert_6` in `../patient007/tests/expert_answers/`). Copied to `/app/findings/`. | agent |
| `environment/study/` | The clinical context PDF (same file as patient007). Copied to `/app/study/`. | agent |
| `solution/solve.sh` | Mechanical oracle summary, for the pipeline smoke test only | oracle |

The agent writes `/app/output/summary.md`, which comes back to the verifier through `artifacts` in
`task.toml`. The reward is currently 1 when the file exists and has a headline and an impression.
Grading the clinical content is not written yet.

## Regenerating the findings

`environment/findings/` comes from the Tally CSV export, generated by `scripts/fill_from_csv.py`:

```bash
python3 scripts/fill_from_csv.py --form form.json --csv "Echo Findings (TTE)_Submissions_<date>.csv" \
  --email alex.ryzhikov@gmail.com --templates tasks/patient007/environment/report_template \
  --out tasks/patient007-summary/environment/findings
```

`form.json` is the raw output of the Tally MCP `load_form` tool for form `8NqplO`. Keep the CSV out of git:
it contains every expert's email address.
